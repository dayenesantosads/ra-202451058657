# Trabalhos — Arquitetura de Aplicações Web

Este espaço reúne os trabalhos, projetos e atividades avaliativas desenvolvidos durante a disciplina de **Arquitetura de Aplicações Web (AAW)**.

A organização dos trabalhos tem como objetivo manter minhas entregas centralizadas e bem estruturadas, facilitando o acompanhamento das atividades realizadas e da minha evolução ao longo da disciplina.

## 📚 Organização

Cada trabalho possui sua própria pasta, seguindo o padrão definido para o repositório:

    trabalhos/
    ├── trabalho-01/
    ├── trabalho-02/
    ├── trabalho-03/
    └── ...

Dentro de cada pasta `trabalho-XX` devem ficar todos os arquivos relacionados à respectiva entrega.

### Exemplo

    trabalhos/
    ├── trabalho-01/
    │   ├── README.md
    │   └── arquivos-do-trabalho/
    ├── trabalho-02/
    │   ├── README.md
    │   └── arquivos-do-trabalho/
    └── trabalho-03/
        └── arquivos-do-trabalho/

## 💻 Entregas

Cada atividade avaliativa deve ser armazenada dentro da pasta correspondente ao trabalho.

Sempre que necessário, a pasta de cada trabalho pode conter um `README.md` próprio, com informações sobre o objetivo da atividade, tecnologias utilizadas, instruções para execução e demais detalhes relevantes para a entrega.

## 🔀 Commits

Ao realizar ou atualizar um trabalho, as alterações devem ser registradas no GitHub.

O padrão de commit utilizado para esta disciplina será:

    git add .
    git commit -m "AAW - Trabalho 01 - <tema>"
    git push

O prefixo `AAW` identifica que a atividade pertence à disciplina de **Arquitetura de Aplicações Web**.

## 📌 Regras de organização

- Cada trabalho deve possuir uma pasta própria.
- As pastas devem seguir o padrão `trabalho-01`, `trabalho-02`, `trabalho-03`...
- A numeração dos trabalhos deve seguir a ordem em que forem propostos.
- Todos os arquivos relacionados à entrega devem permanecer dentro da pasta correspondente.
- Ao finalizar ou atualizar um trabalho, as alterações devem ser commitadas e enviadas ao GitHub.
- As mensagens de commit devem utilizar o prefixo `AAW`.

## 🎯 Objetivo

Este diretório funciona como um espaço para organizar minhas entregas da disciplina de **Arquitetura de Aplicações Web**.

Além de manter os trabalhos organizados, a intenção é construir um histórico das atividades avaliativas realizadas durante o semestre e acompanhar minha evolução na aplicação dos conhecimentos adquiridos ao longo da disciplina.
