# Aulas — Arquitetura de Aplicações Web

Este espaço reúne as atividades, exercícios e práticas desenvolvidas durante as aulas de **Arquitetura de Aplicações Web (AAW)**.

A organização por aula tem como objetivo manter meu aprendizado registrado de forma clara, permitindo acompanhar minha evolução ao longo da disciplina e consultar posteriormente os conteúdos e exercícios realizados.

## 📚 Organização

Cada aula possui sua própria pasta, seguindo o padrão definido para o repositório:

    aulas/
    ├── aula-01/
    ├── aula-02/
    ├── aula-03/
    ├── aula-04/
    └── ...

Dentro de cada pasta `aula-XX` ficam os arquivos e exercícios desenvolvidos durante o respectivo encontro.

### Exemplo

    aulas/
    ├── aula-01/
    │   ├── exercicio-01/
    │   └── exercicio-02/
    ├── aula-02/
    │   └── exercicio-01/
    └── aula-03/
        └── exercicio-01/


## 💻 Atividades

Os exercícios desenvolvidos em cada aula devem ser mantidos dentro da pasta correspondente ao encontro.

Dessa forma, cada aula terá seu próprio espaço, facilitando a organização dos arquivos e permitindo acompanhar o que foi desenvolvido ao longo da disciplina.

## 🔀 Commits

Ao finalizar cada aula, as alterações devem ser registradas no GitHub.

O padrão de commit utilizado para esta disciplina será:

    git add .
    git commit -m "AAW - Aula 01 - exercícios de <tema>"
    git push

O prefixo `AAW` identifica que a atividade pertence à disciplina de **Arquitetura de Aplicações Web**.

## 📌 Regras de organização

- Cada aula deve possuir uma pasta própria.
- As pastas devem seguir o padrão `aula-01`, `aula-02`, `aula-03`...
- A numeração das aulas deve utilizar sempre dois dígitos.
- Os exercícios devem permanecer dentro da pasta da aula correspondente.
- Ao final de cada aula, as alterações devem ser commitadas e enviadas ao GitHub.
- As mensagens de commit devem utilizar o prefixo `AAW`.

## 🎯 Objetivo

Este diretório funciona como um registro das atividades práticas realizadas durante a disciplina de **Arquitetura de Aplicações Web**.

Mais do que apenas armazenar os arquivos das aulas, a intenção é construir um histórico do meu aprendizado, registrar as práticas realizadas e acompanhar minha evolução durante o semestre.
